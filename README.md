# dsh-memgate · 记忆门（插件）

把「检索先行／记忆三域／写入回仓」变成常驻条款 + 一个真能搜的检索工具。

## 为什么原生实现

这族的主力件两个都坏了：

- `统一搜索器.py`：跑起来直接打印「[错误] rg不可用·请用Grep工具替代」——**它自己不能用 rg**；
- `记忆全域查.py`：跑完零输出、静默空转，根还写死 `<workspace>`。

包壳＝把空转搬进提示。所以本插件直接调系统 ripgrep；rg 不在时退回 Node 内扫四文件，保证"至少四文件能搜"。

## 区块 `ql:memory`（默认排序 110）

检索先行三条（先搜再答／零命中≠不存在／死区回溯原文）＋记忆三域（宪法记忆／经历记忆／派生记忆）＋写入回仓三选一（落条款／落台账／落报告）＋记忆的诚实（过期读数标注复验命令）＋判据（这条是搜来的还是想当然）。

## 工具 `ql_memory`

| action | 干什么 |
|---|---|
| `检索` | 按范围全文检索，返回 `文件:行号: 命中行`（默认范围「全部」，可限四文件／脚本／台账／报告） |
| `检索面` | 盘点检索面：四文件体量、scripts 下 `.py` 件数、台账本数、报告件数 |

参数：`query`（关键词）、`scope`（范围枚举）。只读，不写任何文件。

## 配置

| 字段 | 默认 | 含义 |
|---|---|---|
| `enabled` | `true` | 总开关 |
| `order` | `110` | 区块排序 |
| `tool` | `true` | 是否挂工具 |
| `root` | 自动 | 工作区根（四文件＋scripts 签名认定） |

## 诚实边界

- ripgrep 是**词面**检索：同义不同词会漏（"落盘"搜不到"炼化"）。零命中只说明"这个词没出现"，不说明"没有这件事"。
- 大文件（四文件各 65 万字节级）搜起来快，但 `-C 1` 的上下文只有一行；要读全段得回到 read 工具。
- 派生记忆（报告/扫描件）是算出来的，**可以重算**——引用时要标明它是派生物，别当原生事实。
